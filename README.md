# ISO/IEC 27001:2022 GRC Readiness Assessment

A practical **GRC project** demonstrating an ISO/IEC 27001:2022 readiness and gap assessment for a fictional cloud-based organization.

## Overview

This project simulates the role of a **GRC / Information Security Analyst** assessing an organization's Information Security Management System (ISMS) and its readiness for ISO 27001 certification.

The assessment covers:

* ISO 27001 readiness & gap assessment
* Information security risk assessment
* Risk register and risk treatment
* Statement of Applicability (SoA)
* Security control assessment
* Findings and corrective actions
* 90-day remediation roadmap
* Internal audit workpaper
* Certification-readiness evaluation

## Key Skills Demonstrated

`ISO 27001:2022` · `GRC` · `ISMS` · `Risk Management` · `Gap Assessment` · `Internal Audit` · `Statement of Applicability` · `Risk Treatment` · `Compliance` · `Audit Readiness`

## Disclaimer

**CloudNova Analytics Pvt. Ltd. is a fictional organization.** All evidence, risks, findings, and assessment activities are simulated for educational and portfolio purposes. This project does not represent an official ISO/IEC 27001 certification audit.
